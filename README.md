# seo-audit-pro-pricay-policy
Privacy Policy for SEO Audit Pro
Last updated: May 2026
Overview
SEO Audit Pro is a free Chrome/Firefox browser extension that analyzes web pages for SEO quality. We are committed to protecting your privacy. This policy explains what data we collect, how we use it, and your rights.
Data We Collect
We do NOT collect:

Personal information
Browsing history
Any data sent to our servers (we have no servers)
Passwords or sensitive information
Financial information

Data stored LOCALLY on your device only:

Audit results history (stored in your browser's local storage)
Your extension settings and preferences
Your Google PageSpeed API key (stored in Chrome sync storage, encrypted by your browser)
Cached PageSpeed results (stored locally, auto-deleted after 1 hour)

How Your Data Is Used
All analysis happens entirely inside your browser. When you run an audit:

The extension reads the current page's HTML and metadata
All processing is done locally on your device
No page content is ever sent to any external server owned by us

Third Party Services
The only external service this extension communicates with is:
Google PageSpeed Insights API

Used only when you manually click "Run PageSpeed Test"
Requires a free API key that you provide yourself
The URL of the page you are testing is sent to Google's servers
Google's privacy policy applies: https://policies.google.com/privacy
We have no access to this data

RDAP/WHOIS lookup (optional)

Used to retrieve domain registration information
Only the domain name is sent, not full URLs
No personal data is transmitted

IP Geolocation (optional)

Used to display GEO information about the page's server
Only the server IP address is looked up, not your personal IP

Data Sharing
We do not share, sell, rent, or trade any data with any third parties. Ever.
Data Retention
All locally stored data (audit history, settings) stays on your device. You can delete it at any time from the Settings tab using the "Clear History" button. Uninstalling the extension removes all stored data automatically.
Children's Privacy
This extension is not directed at children under 13 and does not knowingly collect data from children.
Changes to This Policy
If we update this policy we will update the "Last updated" date above. Continued use of the extension after changes means you accept the updated policy
